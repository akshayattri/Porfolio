# Akshay Attri — Product Designer

Static portfolio showcasing EasyWebinar, EasyWebinar Live Room, EasyCRM, GoodPaw, and Luma.

## Hosting
Enable GitHub Pages in Settings > Pages. Select Deploy from a branch, main, /(root), and Save.

No build or installation is required. All links and assets are relative for GitHub project-site hosting.

## Editing
Edit index.html for the homepage. Each project has its own HTML case study. Assets are in assets/.
